# Customer-Age-Distribution-in-Karaj-City

## In first person
I open `customers.csv` and read it row by row.  
I check if the row has an `Age` value and if the `City` is `Karaj`.  
If both are true, I take the first two characters of the age field, convert them to an integer, and store it in a list called `vips`.  
Then I count how many times each age appears.  
After that, I split the counts into `x` for ages and `y` for the number of customers.  
Finally, I draw a bar chart with titles, axis labels, a light grid, and display it.

## What it does
In simple terms, this script shows the age distribution of customers in Karaj.  
It is a small data analysis and visualization program.
